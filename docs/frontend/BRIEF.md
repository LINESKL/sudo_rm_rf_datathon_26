# Бриф фронтенда CashGuard

Здесь только **что** нужно и **почему**. Как именно реализовать — решаешь ты.
Обязательные ограничения помечены **[жёстко]**, остальное — рекомендации.

Контекст: `docs/superpowers/specs/2026-10-17-cashguard-design.md` (§5 API, §6 интерфейс).
Мок данных: `docs/frontend/mock_details.json` (нарушения), `mock_details_clean.json` (чисто), `mock_details_processing.json` (в процессе).
Поля карточки: `observed` → «Что видно», `why` → «Почему», `rule` → «Норматив» (может быть `null`), `confidence_level` → уровень уверенности.

---

## 1. Для кого и зачем

- **Проверяющий в банке** загружает запись с камеры кассы и хочет за минуту понять:
  было ли нарушение, где на видео, что именно видно и какое правило нарушено.
  Он не доверяет «чёрному ящику» — ему нужны доказательства.
- **Жюри хакатона** оценивает «Готовность продукта» (10 баллов): удобство, надёжность загрузки, понятность результата.
  Плюс интерфейс будет на питчинге — он должен выглядеть как продукт, а не как студенческий прототип.

Главное ощущение: **«спокойный инструмент проверки, которому можно доверять»**.
Не дашборд с графиками и не тревожная «система безопасности» с красными мигалками.

## 2. Ограничения

1. **[жёстко] Работает офлайн.** Сервис переносят во внутреннюю сеть банка: никаких CDN, внешних шрифтов,
   аналитики и запросов наружу в рантайме. Всё собирается в статику.
2. **[жёстко] Отдаётся бэком как статика** с того же домена: FastAPI раздаёт папку сборки на `/`.
   API на том же origin: `/api/v1/...`.
3. **[жёстко] Контракт API — из спеки §5.** Для экрана используем `GET /api/v1/jobs/{id}/details`
   (там прогресс, таймлайн, нормативы, `preview_url`). Ответ жюри (`/jobs/{id}`) не трогаем.
4. **[жёстко] Язык интерфейса — русский.**
5. Лица на кадрах бэк уже размывает — фронт ничего с этим не делает.

## 3. Стек (рекомендация)

| Что | Рекомендуем | Почему |
|---|---|---|
| Сборка | **Vite** | быстрый старт, сборка в статику, офлайн из коробки |
| UI | **React 18 + TypeScript** | типы под контракт API ловят ошибки до интеграции |
| Стили | **Tailwind CSS** | токены и адаптив без отдельной CSS-архитектуры |
| Компоненты | **shadcn/ui** (Radix, MIT) | доступные диалоги, тултипы, прогресс — копируются в репо, без рантайм-зависимости от CDN |
| Иконки | **lucide-react** | одна линейная библиотека, без эмодзи |
| Запросы и опрос | **TanStack Query** (`refetchInterval`) | опрос статуса, ретраи и кэш без самописа |
| Шрифты | **@fontsource/inter**, **@fontsource/jetbrains-mono** | шрифты в бандле, работают офлайн |

Если удобнее другой стек (Vue, Svelte) — ок, при условии офлайн-сборки в статику. Не бери Next.js с SSR:
сервер у нас FastAPI.

Структура на твоё усмотрение. Сборка кладётся в `frontend/dist`, бэк раздаёт её.
Для разработки — `vite` с прокси `/api` на `localhost:8000`, а до готовности бэка — мок из `mock_details.json`.

## 4. Экран и состояния

Одна страница, один сценарий. Никакой навигации, авторизации, истории.

### 4.1 Загрузка
- Крупная зона drag-and-drop + кнопка выбора файла. Подсказка: «.mov или .mp4, до 200 МБ».
- Проверка формата и размера до отправки; ошибка — рядом с зоной, с тем, как исправить.
- Поле API-ключа (свёрнуто, если ключ уже сохранён). Ключ — в заголовке `X-API-Key`.
- Прогресс отправки файла в процентах.

### 4.2 Обработка (до ~2 минут)
- Шаги с текущим активным: **Подготовка видео → Люди и предметы → Анализ сцены → Проверка находок**
  (из `progress.stage`, значение — `progress.value`).
- Миниатюра первого кадра или имя файла — чтобы было видно, что обрабатывается.
- Текст «Обычно занимает 1–2 минуты». Никаких бесконечных спиннеров без пояснения.
- Ошибка или `failed` — причина человеческим языком и кнопка «Попробовать снова».

### 4.3 Результат
Компоновка на десктопе (≥ 1024 px):

```
┌───────────────────────────────────────────────────────────────┐
│ Баннер вердикта                                  [Новое видео] │
├──────────────────────────────────┬────────────────────────────┤
│ Плеер (preview_url)              │ Список нарушений            │
│ Шкала с метками нарушений        │ ┌ Карточка 1 ─────────────┐ │
│ Дорожки состояний (timeline)     │ │ тип · 00:08,6 · уверен. │ │
│  Кассир на месте ▓▓▓▓░░░░░░      │ │ кадры (1–3)             │ │
│  Деньги на столе ░░▓▓▓▓▓░░       │ │ Что видно / Почему      │ │
│  Экран разблок.  ░░░░▓▓▓▓▓       │ │ Норматив: док, п., цит. │ │
│  ...                             │ └─────────────────────────┘ │
│ (левая колонка «липкая»)         │ ┌ Карточка 2 ...          │ │
├──────────────────────────────────┴────────────────────────────┤
│ Плашка: «Результат — подсказка для проверки человеком»        │
└───────────────────────────────────────────────────────────────┘
```

На мобильном (375 px) — одна колонка: баннер → плеер → дорожки → карточки.

**Баннер вердикта**
- `violation`: «Обнаружены признаки возможных нарушений: 2» — акцентный цвет + иконка.
- `no_violation`: «Нарушение не обнаружено» — нейтрально-позитивный + иконка, под ним «Проверено правил: N».
- Не используем слова «виновен», «нарушитель». Формулировки — «признаки возможного нарушения».

**Плеер**
- `<video>` по `preview_url`, на шкале — метки нарушений (интервал `timecode_sec`–`timecode_end_sec`).
- Клик по метке, таймкоду в карточке или кадру-доказательству → перемотка на момент −1 с и подсветка карточки.
- Активная карточка подсвечивается, когда плеер проходит её интервал.

**Дорожки состояний** — главная «фишка» объяснимости
- Каждая дорожка — интервалы из `timeline`: где кассир на месте, где деньги на столе и т. д.
- Курсор синхронен с плеером, клик по дорожке — перемотка.
- Интервалы, совпадающие с нарушением, подсвечены цветом нарушения.
- Подписи дорожек — по-русски (словарь ключей в мок-файле).

**Карточка нарушения**
- Заголовок: тип нарушения + таймкод `мм:сс,д` (моноширинные цифры) + уверенность (низкая/средняя/высокая, не проценты).
- Кадры-доказательства: 1–3 миниатюры с подписью времени, клик — просмотр крупно (лайтбокс), Esc закрывает.
- **Что видно** — описание наблюдаемого.
- **Почему это может быть нарушением** — короткое пояснение правила.
- **Норматив** — документ, пункт, цитата (свернуть, если длинная), ссылка на adilet (открывается в новой вкладке).
  Если норматива нет — «Норматив не определён, требуется проверка», без пустых блоков.

## 5. Визуальное направление

**Стиль:** чистый, «бумажный» интерфейс проверки. Светлая тема по умолчанию, тёмная — по желанию.
Плоские поверхности, тонкие границы, мягкие тени только у карточек. Радиус 8–12 px. Без градиентов,
стекла и анимаций ради анимаций.

**Цвета (токены, не хардкод в компонентах):**

| Токен | Светлая | Назначение |
|---|---|---|
| `bg` | `#F7F8FA` | фон страницы |
| `surface` | `#FFFFFF` | карточки, панели |
| `border` | `#E3E6EB` | границы, разделители |
| `text` | `#111827` | основной текст |
| `text-muted` | `#5B6472` | вторичный текст (контраст ≥ 4.5:1 на `surface`) |
| `primary` | `#1F4FD8` | кнопки, ссылки, фокус |
| `violation` | `#C2410C` | метки и баннер нарушения (оранжево-красный, не кричащий) |
| `violation-bg` | `#FFF4ED` | фон баннера и подсветки нарушения |
| `ok` | `#15803D` | «нарушение не обнаружено» |
| `ok-bg` | `#F0FDF4` | фон позитивного баннера |
| `lane` | `#94A3B8` | интервалы дорожек без нарушения |

Цвет никогда не единственный носитель смысла: всегда иконка или текст рядом.
Фирменные цвета и логотип ForteBank **не используем** — продукт наш, не их.

**Типографика:** Inter для интерфейса (400 текст, 500 подписи, 600 заголовки), JetBrains Mono для таймкодов
и времени. Шкала 12 / 14 / 16 / 20 / 24 / 32. Текст 16 px, межстрочный 1.5.

**Отступы:** сетка 4/8 px; между секциями 24–32 px; max ширина контента 1280 px.

**Движение:** 150–250 мс, только смена состояний и подсветка карточки; уважать `prefers-reduced-motion`.

## 6. Качество (проверим перед сдачей)

- [ ] Доступность: фокус видим, всё работает с клавиатуры (загрузка, плеер, лайтбокс, ссылки), контраст ≥ 4.5:1.
- [ ] 375 px без горизонтальной прокрутки; 1440 px не растягивается в ленту.
- [ ] Нет «прыжков» вёрстки при загрузке кадров: размеры миниатюр заданы.
- [ ] Ошибки сети, `401`, `400`, `failed`, таймаут — у каждой понятный текст и действие.
- [ ] Видео с 0, 1 и 3+ нарушениями выглядят аккуратно; длинные описания и цитаты не ломают карточку.
- [ ] Сборка работает без интернета (проверить с выключенной сетью).
