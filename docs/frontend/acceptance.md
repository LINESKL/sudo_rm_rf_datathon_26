## Подключение frontend к FastAPI — 17.10.2026

Источник frontend: `origin/feat/F1-upload-status`, `f34d07b`.
Подключено в рабочем дереве `dunan/backend-video-processing` поверх ML-интеграции
`ef84795`. Frontend production-сборка обслуживается FastAPI с того же origin.
RunPod не арендовался. Проверка использовала `ml.stub:analyze`: это настоящий
HTTP API, очередь, FFmpeg и сохранение результатов, но не инференс нейросети.

### Изменения

- Добавлены полные карточки событий, точные таймкоды, уровень уверенности,
  наблюдение, объяснение, норматив при наличии и 1–3 JPEG без обрезания.
- Кадр открывается крупно; Esc закрывает просмотр и возвращает фокус.
- Плеер использует `preview_url` и HttpOnly cookie от `/details`, поддерживает
  переход к событию с контекстом −1 с, метки событий и обновление доступа.
  Ошибка видео не скрывает кадры и текст. API-ключ не включается в URL.
- Клиент согласован с nullable/отсутствующими `rule.point` и `rule.quote`.
  `degraded` и противоречивый вердикт отклоняются; внешнее превью не загружается.
- Dev-прокси теперь обслуживает `/api` и `/previews`; production не использует демо.
- Окончания строк frontend закреплены как LF для воспроизводимости Prettier на Windows.

### Проверки

- [x] Node **24.19.0**, production build, ESLint и Prettier — успешно.
  Системный Node 22.14.0 ниже требования пакетов, поэтому проверки выполнялись на Node 24.
- [x] **79 frontend-тестов**: API, polling, состояния загрузки, карточки 0/1/4 событий,
  необязательные реквизиты источника, повреждённый JPEG, недоступное/внешнее превью,
  обновление доступа, возврат фокуса, противоречивые и неполные ответы.
- [x] Браузер **Codex IAB**, адрес `http://127.0.0.1:8000`: реальная загрузка MOV →
  processing → done, карточка, JPEG, плеер; демо API Vite не использовался.
- [x] В UI обработаны `Х-37.mov` (**3 247 107 байт, 15,866667 с**) и `Х-14.mov`

## Docker с frontend: офлайн-приёмка — 17.10.2026

Проверен CPU-образ `cashguard:stub-frontend-offline`, собранный поверх исходников
`14d9a75` с доработками Docker. Локальный image ID:
`sha256:41399acf2c33359b282b475960e3d6b91f4ac7a8cca316f05e7ef19eb3f22082`.
Docker Desktop 4.43.1 / Engine 28.3.0, Linux amd64; анализатор `ml.stub:analyze`.
Образ не публиковался в registry. RunPod не арендовался.

- [x] Docker сам собирает production frontend на Node 24.19.0 по lock-файлу.
  Локальный dist исключён из контекста; JSON-примеры контрактов доступны TypeScript
  на этапе сборки. Статика копируется в CPU- и GPU-цели, но GPU-цель здесь не собиралась.
- [x] `--pull never --network none`: только интерфейс lo, внешний TCP недоступен
  (`Network is unreachable`). `pip check` прошёл.
- [x] `deploy.frontend_check`: **9 файлов, 476 421 байт** — index, JS, CSS,
  локальные шрифты и favicon. Все HTTP-ответы побайтно совпали с файлами образа.
- [x] Исходный `Х-14.mov`, **28 718 927 байт / 142,533 с**: HTTP-приёмка
  за **14,665 с**, согласованные jury/details, JPEG, H.264/yuv420p/faststart,
  приватное превью, HEAD/Range. Шесть загрузок завершились за **23,632–48,693 с**;
  все шесть результатов доступны после рестарта.
- [x] Браузер Codex IAB загрузил тот же MOV через production UI в отдельный
  контейнер **того же образа с --network none**, получил done, карточку и JPEG.
  Серверное processing_sec браузерного задания — **15,644 с**.
- [x] Play/pause, перемотка до **72,610533 с** (readyState=4, ошибок media нет),
  переход по событию, увеличение JPEG, Esc с возвратом фокуса и обновление доступа
  с сохранением позиции 72,610533 с.
  Проверены согласованность API браузерного задания и Range 206 на 100 байт.
- [x] JS/CSS загружены с локального origin, шрифты loaded, JPEG 640×1170 читается.
  Предупреждений и ошибок console нет. Заглушка явно обозначена в результате.

Для браузера использован `deploy/offline-browser.py`: локальный HTTP-мост через
`docker exec` к loopback контейнера. Порты контейнера не опубликованы, сетевой режим
остаётся none. Мост добавляет CSP, запрещающую внешние script/style/font/media/API
ресурсы (для JPEG разрешён data URL), и отключает кеш. Ответы сервиса не подменяются.
Интернет Windows-хоста целиком не отключался; изолированы контейнер и ресурсы страницы.
Накладные расходы тестового моста не использовать для оценки production SLA.
