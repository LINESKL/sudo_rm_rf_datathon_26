# Open Sans

Локальные файлы Open Sans variable 300–800, фактически загруженные [референсом Forte](https://forte.kz/ru) 17.10.2026. Лицензия SIL Open Font License 1.1 находится в `OFL.txt`; источник лицензии — `google/fonts/ofl/opensans`.

- `open-sans-latin.woff2`: https://forte.kz/_next/static/media/cf514f5d0007dafa.p.1wc2mf9hp9pav.woff2
- `open-sans-cyrillic.woff2`: https://forte.kz/_next/static/media/7cdbb9ca823c0a73.p.1h6d36qg8q9eb.woff2
- `open-sans-cyrillic-ext.woff2`: https://forte.kz/_next/static/media/3ce154ad7d54dc86.1-9go8whdf-l6.woff2

Unicode ranges взяты из CSS референса, `font-display: swap` выбран для локального приложения. Runtime использует только локальные файлы через `frontend/src/styles.css`.
